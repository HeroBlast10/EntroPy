<a name="what-is-factor"></a>
## 1. 什么是"因子"？

**一句话定义**：因子是一个数值信号，能够在截面上（同一时间、不同股票之间）预测未来一段时间的超额收益。

### 直觉类比

想象你是一个图书馆管理员，面前有 500 本书。你想预测哪些书本月会被借出最多次。你可以看：
- 书的出版日期（类比：动量 — 近期热门）
- 书的厚度（类比：波动率 — 信息密度）
- 借阅等待队列长度（类比：流动性）
- 豆瓣评分（类比：质量因子）

每个角度都能给你一个"信号"。量化研究的目标就是找到这些信号中**稳定、可重复、成本可覆盖**的部分。

### 因子研究的核心流程

```
原始因子值 → 截面标准化 → 有效信号 → IC评估 → 筛选 → 组合
```

### 关键概念速查

| 概念 | 含义 | 面试常问 |
|------|------|----------|
| IC (Information Coefficient) | 因子值与下期收益的截面相关系数 | "你的IC是多少？" |
| RankIC | IC的秩相关版本（更稳健） | "为什么用RankIC而不是IC？" |
| ICIR | IC均值 / IC标准差 × √252，信噪比 | "ICIR超过0.5才够用" |
| 换手率 | 因子排名日间变化，越大实盘成本越高 | "你的因子换手率高吗？" |
| Alpha半衰期 | IC衰减到初始值一半所需的天数 | "应该多久再平衡一次？" |
| 方向 (+1/-1) | +1=高值更好；-1=低值更好（需取反） | "为什么低波动是正因子？" |

<a name="factor-lifecycle"></a>
## 2. 因子的生命周期

```
发现 → 验证 → 筛选 → 组合 → 上线 → 监控 → 退役
```

### 第一步：发现
- 来源：学术论文 / 行业直觉 / 数据挖掘
- 工具：`FactorBase._compute()` — 每个因子类只需实现原始计算逻辑

### 第二步：验证（有效性检验）
核心指标：
- **IC均值 > 0.02**：信号方向正确，有微弱但持续的预测力
- **NW t-stat > 2.0**：统计显著（用Newey-West修正，因为IC序列有自相关）
- **ICIR > 0.3**：稳定性够用于组合

### 第三步：筛选（生产级过滤）
七维过滤，任何一维不合格都建议拒绝：

```
统计显著性 × 时间稳定性 × 经济显著性 × 容量 × 拥挤度 × 截面宽度 × 实施成本
```

### 第四步：组合
不是简单等权平均，而是：
- Rolling ICIR 加权
- 均值-方差优化
- 风险平价
- 正交增量 alpha（核心：只提取"新信息"）

### 第五步：监控
- 每月检查 IC 是否持续衰退
- 检查因子拥挤度（大量资金涌入会让信号消失）
- 容量弹性：资金翻倍时净Sharpe衰减多少？

<a name="momentum"></a>
## 3. 动量类因子

### 动量的经济学来源

股价动量（Jegadeesh & Titman 1993）是最古老也是最难解释的异象之一。主要解释有三种：

1. **行为金融**：投资者对好消息反应不足（underreaction），导致利好在数月内缓慢消化
2. **正反馈机制**：上涨→资金流入→继续上涨（价格正反馈）
3. **风险定价**：动量股票承担了"动量风险"，高收益是对尾部风险的补偿

### MOM_1M — 1个月动量

| 属性 | 值 |
|------|-----|
| 公式 | `close(t) / close(t-21) - 1` |
| 方向 | +1（越高越好）|
| 换手率 | 较高（月度全换） |
| 注意 | 这其实是短期反转的反向使用 |

**直觉**：上个月涨了10%的股票，这个月继续涨的可能性略高于市场平均。

### MOM_3M / MOM_6M — 3/6个月动量

同理，lookback窗口更长，信号更稳定，但反应更慢。6个月是性价比最好的窗口之一。

### MOM_12_1M — 经典12-1动量（Jegadeesh-Titman原版）

| 属性 | 值 |
|------|-----|
| 公式 | `close(t-21) / close(t-252) - 1`（跳过最近1个月） |
| 为什么跳过最近1个月？ | 最近1个月的收益有强烈的均值回复，加入会抵消信号 |
| lag参数 | `lag=21`（在FactorMeta中） |
| 文献 | Jegadeesh & Titman (1993) |

**面试要点**：一定要解释 "skip 1 month" 的原因 — 这是区分了解和不了解动量因子的关键细节。

### STR_1W / STR_1M — 短期反转

| 属性 | 值 |
|------|-----|
| 公式 | `-close(t) / close(t-21) + 1`（取反） |
| 方向 | -1（低动量 = 高反转 = 买入信号）|
| 原理 | 过去1个月大跌的股票，下个月平均反弹（流动性提供者赚取反转溢价）|

**直觉**：上个月跌了20%的股票，短期内大概率有反弹，因为过度悲观的卖方平仓后，价格回归均值。

### MOM_PATH — 路径依赖动量

| 属性 | 值 |
|------|-----|
| 公式 | `12月累积收益 / |最大回撤|` |
| 方向 | +1 |
| 动机 | 同样是+15%的收益，平稳上涨比大起大落的质量更高 |
| 文献 | Daniel & Moskowitz (2016) "Momentum Crashes" |

**面试要点**：这是对 momentum crash 的应对 — 动量崩溃通常发生在过去路径非常波动的情况下。用路径质量过滤可以减少这种尾部风险。

<a name="volatility"></a>
## 4. 波动率类因子

### 低波动异象的悖论

经典金融理论（CAPM）说高风险=高收益。但实证研究发现 **低波动率股票长期跑赢高波动率股票**，这是量化中最大的悖论之一。

主要解释：
- **委托-代理问题**：机构投资者有业绩比较基准，倾向于持有"够刺激"的高β股票，导致这些股票被高估
- **彩票效应**：散户爱买"可能一夜暴富"的高波动股，推高价格
- **杠杆约束**：要追求高收益但有杠杆上限的机构，会买入高β股票，导致低β被低估

### VOL_20D / VOL_60D — 已实现波动率

| 属性 | 值 |
|------|-----|
| 公式 | `std(log_return) × √252`，20天/60天滚动窗口 |
| 方向 | -1（低波动 = 好信号） |
| 使用场景 | 截面选股：买低波动、卖高波动 |

**一个重要点**：这是截面因子（比较同一时间点的不同股票），不是时序因子（比较同一股票的不同时间）。

### IDIOVOL — 特质波动率

| 属性 | 值 |
|------|-----|
| 公式 | CAPM回归后残差的标准差 |
| 步骤 | 1. 对每支股票，60天滚动回归 `r_stock = α + β × r_market + ε`；2. 取 `ε` 的标准差 |
| 方向 | -1 |
| 意义 | 剔除了市场因子的"纯粹股票特有风险"，比总波动率更干净 |

**面试要点**：当面试官问"为什么用特质波动率而不是总波动率"，回答：总波动率包含了市场系统性风险，而特质波动率更接近"这支股票自身的不确定性"。

### SKEW_60D / KURT_60D — 偏度和峰度

| 属性 | 含义 | 方向 |
|------|------|------|
| SKEW | 负偏度 = 厚左尾 = 崩盘风险 → 风险溢价 | +1（更正偏度 = 更好？注意实证方向可能不一） |
| KURT | 高峰度 = 更多极端值 = 尾部风险更大 | -1 |

**注意**：SKEW的方向在不同文献中有争议。一些研究认为高正偏（彩票效应）导致股票被高估，方向应为-1。EntroPy默认+1（更正偏 = 更少崩溃风险），具体使用时根据样本实证调整。

### VOL_OF_VOL — 随机波动率代理

| 属性 | 值 |
|------|-----|
| 公式 | 对20天滚动波动率，再计算60天滚动标准差 |
| 经济含义 | 波动率本身的不稳定性 — 高VoV的股票，风险难以预测 |
| 物理类比 | 就像湍流中湍流强度的方差，这是更高阶的随机性度量 |

### TAIL_RISK — 条件风险价值（CVaR）

| 属性 | 值 |
|------|-----|
| 公式 | 过去60天最坏5%日收益的均值（Expected Shortfall） |
| 方向 | -1（尾部风险越大越不好） |
| 优势 | 比VaR更"一致"（满足次可加性），Basel III标准 |

### REALIZED_JUMP — 已实现跳跃

| 属性 | 值 |
|------|-----|
| 公式 | `1 - BV / RV`（二变差与已实现方差之比） |
| 物理意义 | 价格方差中有多少来自"跳跃"（不连续运动）vs 扩散 |
| 文献 | Barndorff-Nielsen & Shephard (2004) |

**为什么重要**：跳跃是非扩散风险，不能用Black-Scholes对冲。高跳跃比例的股票面临更多尾部风险。

<a name="liquidity"></a>
## 5. 流动性类因子

### 流动性的核心逻辑

**非流动性溢价**：持有难以买卖的股票是有代价的（交易成本高、紧急时难以退出）。理性投资者要求更高预期收益来补偿这个风险。

### ILLIQ_AMIHUD — Amihud非流动性

| 属性 | 值 |
|------|-----|
| 公式 | `mean(|r_t| / dollar_volume_t)` 过去20天 |
| 直觉 | 每单位美元成交量能移动多少价格。越高 = 越不流动 = 潜在溢价越高 |
| 方向 | -1（用负方向：高非流动性 = 未来高收益） |
| 文献 | Amihud (2002) |

**面试金句**：Amihud不流动性是量化中最被认可的流动性因子，比bid-ask spread更容易获取（日频OHLCV数据就够），且实证效果稳健跨市场。

### TURNOVER_20D / TURNOVER_60D — 成交量换手

| 属性 | 值 |
|------|-----|
| 公式 | `volume_t / median_volume_60d`（相对换手） |
| 方向 | -1（高换手 = 吸引了太多关注 = 可能被高估） |
| 理论 | Chordia et al.: 高换手股票往往是散户热情买入的股票，未来收益偏低 |

### SPREAD_HL — 日内价差代理（Corwin & Schultz）

| 属性 | 值 |
|------|-----|
| 公式 | 基于日线 High/Low 估计隐含买卖价差 |
| 优势 | 只需日频数据就能估计微结构成本 |
| 方向 | -1（大价差 = 更高交易成本 = 更高非流动性溢价） |
| 文献 | Corwin & Schultz (2012) |

### PRICE_IMPACT — 价格冲击代理（Kyle's λ）

| 属性 | 值 |
|------|-----|
| 公式 | 回归 `|r_t|` 对 `signed_volume_t`，取斜率 |
| 经济含义 | 每单位净买入导致的价格变动（Kyle 1985 λ参数） |
| 方向 | -1 |

<a name="value-quality"></a>
## 6. 价值与质量类因子

### 价值的核心逻辑

价值因子寻找"便宜"的股票 — 基本面价值相对市价被低估的公司。

**注意（关键风险）**：便宜可能是"价值陷阱"（公司确实在走下坡路）。质量因子可以帮助区分"便宜+好"和"便宜+烂"。

### EARNINGS_YIELD — 盈利率（E/P）

| 属性 | 值 |
|------|-----|
| 公式 | `TTM净利润 / 市值` |
| TTM | 过去12个月的总和（消除季节性） |
| 方向 | +1（E/P越高 = 越便宜） |
| PIT处理 | 财报有45-90天的披露滞后，必须用`publish_date`而不是`fiscal_period_end` |
| 文献 | Fama & French (1992) |

**面试必答点**：为什么用TTM而不是最近季度？因为很多公司有季节性（零售商Q4利润最高），TTM消除了这个噪音。

### BOOK_TO_MARKET — 账面市值比（B/M）

| 属性 | 值 |
|------|-----|
| 公式 | `股东权益 / 市值` |
| 方向 | +1（高B/M = 价值股，Fama-French HML因子的多方） |
| 文献 | Fama & French (1993) |

**经济学解释之争**：
- 理性解释（FF）：B/M是系统性风险代理，高B/M公司在经济衰退期表现最差，投资者要求风险溢价
- 行为解释（Lakonishok）：市场对"无聊的价值股"过度悲观，导致低估

### GROSS_PROFITABILITY — 毛盈利率

| 属性 | 值 |
|------|-----|
| 公式 | `TTM毛利润 / 总资产` |
| 方向 | +1（更高 = 更好） |
| 文献 | Novy-Marx (2013) "The Other Side of Value" |

**为什么用毛利润而不是净利润**：净利润受会计政策影响大（折旧方法、一次性费用等），毛利润离产品经营本身更近，是"最干净"的盈利能力指标。

**面试金句**：Novy-Marx 2013 的发现让很多人惊讶——盈利能力和B/M（价值）是**正交**的，能够相互增强，是Fama-French 5因子模型（RMW）的理论基础。

### ASSET_GROWTH — 资产增长

| 属性 | 值 |
|------|-----|
| 公式 | `total_assets_t / total_assets_{t-1y} - 1` |
| 方向 | -1（低资产增长 = 好）|
| 文献 | Cooper, Gulen & Schill (2008) |

**直觉**：大量资产扩张（大规模融资、收购）往往是管理层过度自信的信号。事后看，这些扩张通常回报不佳。"投资保守的公司跑赢激进扩张的公司"就是这个因子的核心。

<a name="new-factors"></a>
## 7. 新增生产级因子（本次更新）

这部分描述在 v0.9 更新中新增的四个因子，它们代表当前 buy-side 团队普遍使用但初学者少接触的"信息边缘"类信号。

### ACCRUALS — 应计项目（Sloan 1996）

| 属性 | 值 |
|------|-----|
| 公式 | `(净利润_TTM - 经营性现金流_TTM) / 总资产` |
| 方向 | -1（低应计 = 好） |
| 文献 | Sloan (1996) The Accounting Review |

**核心逻辑（非常重要）**：

盈利 = 现金盈利 + 应计项目

- 现金盈利 = 真实收到的钱（经营性现金流）
- 应计项目 = 会计记账产生的"利润"（比如应收账款增加、存货增加）

应计项目的持续性差。高应计意味着"纸面利润"多于"真实现金"。Sloan 1996 发现市场对这个区别反应不足，高应计公司未来平均跑输市场。

**一句话口诀**："会计师能让利润好看，但现金是不撒谎的。"

**面试谈资**：这个因子的发现（1996年）在当时轰动了学术界，因为"市场不能识别应计项目的低质量"挑战了半强式有效市场假说。后来大量资金涌入，信号逐渐衰减，但在机构覆盖度低的小盘股中仍然显著。

### PIOTROSKI_F8 — Piotroski 基本面综合评分（8维版）

| 属性 | 值 |
|------|-----|
| 公式 | 8个二元指标之和（0-8分） |
| 方向 | +1（分数越高 = 基本面改善越多） |
| 文献 | Piotroski (2000) Journal of Accounting Research |

**8个指标详解**：

| 序号 | 指标 | 判断逻辑 |
|------|------|----------|
| F1 | ROA > 0 | 公司有在盈利 |
| F2 | CFO > 0 | 经营活动产生正现金流 |
| F3 | ΔROA > 0 | 盈利能力在改善 |
| F4 | CFO > 净利润 | 现金盈利质量高（应计低）|
| F5 | 负债率下降 | 财务结构在优化 |
| F6 | 未新发股票 | 不需要稀释股权融资 |
| F7 | 毛利率提升 | 定价能力在增强 |
| F8 | 资产周转率提升 | 资产使用效率在提升 |

**为什么是8维而不是原版9维**：原版第9个指标需要流动比率（流动资产/流动负债），当前数据源无法可靠分离流动/非流动部分，因此省略。实证显示8维版本保留了原版90%的预测力。

**使用场景**：Piotroski分数在价值股中效果最强——先用B/M筛出便宜的公司，再用F-Score识别"便宜且在改善"的公司。这是"价值+质量"复合策略的经典实现。

### RESID_MOM_12_1M — 残差动量（Blitz-Huij-Martens 2011）

| 属性 | 值 |
|------|-----|
| 公式 | 在滚动市场/规模因子回归后，过去12-1个月的累计残差收益 |
| 方向 | +1 |
| 文献 | Blitz, Huij & Martens (2011) Journal of Empirical Finance |

**为什么用"残差"动量而不是"原始"动量**：

原始价格动量有一个严重问题：动量暴露会随市场环境变化。在市场急涨时，高β股票（高动量）会跑赢；市场急跌时（比如2008、2020年3月），动量策略会经历"动量崩溃"（momentum crash）。

残差动量的关键改进：
1. 对每只股票做滚动多因子回归，提取纯粹的特质趋势
2. 去掉了市值和市场因子的影响
3. 结果：动量崩溃风险大幅降低，Sharpe比更稳定

**物理直觉**：就像用残差分析区分信号和噪声。市场的动量崩溃其实是系统性因子的反转，而特质层面的趋势更持续。

### OVERNIGHT_RET_21D — 隔夜收益因子（Lou-Polk-Skouras 2019）

| 属性 | 值 |
|------|-----|
| 公式 | `mean(open(t) / close(t-1) - 1)` 过去21天 |
| 方向 | +1（过去21天平均隔夜收益高 = 未来涨） |
| 数据需求 | 需要 `open` 和 `close` 价格 |
| 文献 | Lou, Polk & Skouras (2019) Journal of Financial Economics |

**核心发现（非常反直觉）**：

研究发现：
- **隔夜收益**（今天开盘 / 昨天收盘 - 1）具有**正向持续性**——过去隔夜持续上涨的股票，未来也倾向于隔夜上涨
- **日内收益**（今天收盘 / 今天开盘 - 1）具有**均值回归**——日内强势的股票，次日日内倾向于走弱

**经济学解释**：隔夜期间，散户订单和ETF申购赎回在开盘前累积。持续获得资金流入的股票，其隔夜上涨反映了真实的需求压力，而不只是日内噪声。

**特别说明**：这个因子在散户交易占比高的市场（如A股、美国散户化严重的小盘股）效果可能更强。

<a name="time-series"></a>
## 8. 时间序列特征因子

时序因子与截面因子的核心区别：

- **截面因子**：在同一时间比较不同股票（"这只股票比那只便宜吗？"）
- **时序因子**：分析单只股票自身的时间序列属性（"这只股票现在是趋势状态还是均值回复状态？"）

### KF_VELOCITY — Kalman 滤波趋势速度

| 属性 | 值 |
|------|-----|
| 状态空间模型 | `[价格, 速度]` 的 constant-velocity 模型 |
| 提取量 | 当前价格趋势的"速度"（每日变化率的滤波估计）|
| 方向 | +1（上升趋势速度为正） |

**为什么用Kalman而不是简单移动平均**：

移动平均有滞后（lag）问题 — 趋势已经结束了，均线还没反应。Kalman滤波是最优线性估计器，在给定噪声假设下，对趋势方向的估计延迟最小。

**物理学背景**：Kalman滤波原本用于阿波罗计划的轨迹修正。状态方程 `[位置, 速度]` 和价格序列 `[价格, 趋势速度]` 在数学结构上完全一样。这也是 EntroPy 这个项目名的物理学内涵所在。

### KF_TREND_STRENGTH — 趋势强度

| 公式 | `velocity / filtered_price`（无量纲化趋势强度）|
| 方向 | +1 |

### KF_NOISE_RATIO — 噪声比率

| 公式 | `|raw_price - filtered_price| / |filtered_price|` |
| 方向 | -1（噪声越高 = 趋势信号越弱 = 买入信号越不可靠）|

### SPECTRAL_ENTROPY_60D — 谱熵

| 属性 | 值 |
|------|-----|
| 公式 | 对60天收益做DFT（离散傅里叶变换），对功率谱计算Shannon熵 |
| 方向 | -1（低熵 = 价格有周期性结构 = 可预测性高）|

**直觉**：
- 纯随机游走的功率谱很平坦（高熵）— 什么周期都没有，不可预测
- 有趋势或周期结构的股票，功率谱有峰值（低熵）— 可预测性更强

**EntroPy 的物理学内涵**：熵是热力学的核心量，也是信息论的核心量。高熵 = 更混乱 = 更难预测，低熵 = 更有序 = 更可预测。用谱熵量化股价的"有序性"，是将物理学视角带入量化金融的代表性尝试。

### HURST_60D — Hurst 指数

| 属性 | 值 |
|------|-----|
| 公式 | R/S 分析（Rescaled Range Analysis） |
| 方向 | +1（高Hurst = 更强趋势持续性）|

**Hurst指数解读**：
- H = 0.5：随机游走（无预测性）
- H > 0.5：趋势持续（追势策略有效）
- H < 0.5：均值回复（反转策略有效）

**实践中**：大多数股票的 H 在 0.45-0.55 之间，差异非常微小，但截面上的相对排序有预测价值。

<a name="regime"></a>
## 9. Regime 覆盖因子

### HMM_TURBULENCE_PROB — HMM 市场状态概率

| 属性 | 值 |
|------|-----|
| 模型 | 2状态高斯隐马尔可夫模型（calm / turbulent）|
| 训练 | Baum-Welch EM 算法（自行实现，未用 hmmlearn）|
| 输出 | `P(当前状态 = 高波动)`，0-1之间 |
| 用途 | Regime overlay：当 P > 0.6 时，组合净暴露降至50% |

**HMM的工作方式**（简化版）：
1. 假设市场在两个隐藏状态之间切换：平静期（低波动）和动荡期（高波动）
2. 每个状态下，收益率服从不同的高斯分布
3. Baum-Welch算法从历史数据中估计状态转移概率和各状态的均值/方差
4. 给定最新观测，计算"当前处于动荡状态"的后验概率

**注意**：这不是一个 alpha 因子，而是**风险管理信号**。当市场进入动荡 regime，所有 alpha 因子的预测能力都会下降，同时组合的风险敞口应该缩小。

<a name="relative-value"></a>
## 10. 相对价值因子

### OU_ZSCORE — Ornstein-Uhlenbeck 均值回复信号

| 属性 | 值 |
|------|-----|
| 模型 | `dX_t = θ(μ - X_t)dt + σdW_t` （OU过程）|
| 参数估计 | 最大似然估计（MLE）|
| 输出 | 当前偏离长期均值的标准化距离（z-score）|
| 方向 | +1（低于均值时为负 → 买入信号）|

**物理直觉**：OU过程描述橡皮筋弹力 — 拉得越远，弹回的力量越大。在金融中，均值回复的股票（配对交易策略）就类似这种"弹力"。

参数 `θ`（回复速度）越大，均值回复越快，适合短期交易；`θ` 越小，适合更长周期的持有。

<a name="interview-tips"></a>
## 11. 如何在面试中谈因子

### 谈IC（信息系数）时

✅ 好的回答：
> "我的 MOM_12_1M 因子在美股2010-2024年的样本中，RankIC均值为 0.038，NW HAC调整后的t统计量为 4.2（用Newey-West修正是因为使用了5日前向收益，相邻观测有重叠导致自相关）。FDR q-value 为 0.07，通过了10%显著性水平的多重检验控制。"

❌ 一般的回答：
> "IC大概是0.04左右。"

**关键区别**：用 NW t-stat 而不是 i.i.d. t-stat，体现了对统计方法的理解。

### 谈换手率时

✅ 好的回答：
> "该因子的日均换手率约为 15%，对应20天再平衡频率下的平盈成本约为 8bps。根据IC衰减分析，alpha半衰期约为 12 天，因此设置10天再平衡是性价比最好的选择——既能捕获大部分alpha，又将换手控制在合理范围。"

❌ 一般的回答：
> "换手率还可以，不太高。"

### 谈过拟合防控时

✅ 好的回答：
> "我做了三层防控：(1) Benjamini-Hochberg FDR，控制在10%的虚假发现率；(2) 完整版 CSCV（Bailey et al. 2017），枚举 C(10,5)=252 个分割组合，PBO 为 0.18，说明IS最优因子有 82% 的概率在OOS排名靠前；(3) 滚动 walk-forward，36个月训练/12个月测试，OOS Sharpe 0.73±0.25。"

❌ 一般的回答：
> "我做了 walk-forward，OOS结果还不错。"

### 谈多因子组合时

✅ 好的回答：
> "我比较了4种组合方法：等权z-score、rolling ICIR加权、均值-方差优化、正交增量alpha。正交增量的原理是先将高阶信号（Kalman速度、谱熵）对基础CS因子（动量、流动性）正交，再组合，这样只提取了真正的增量信息，避免了与已知因子的重复计数。OOS Sharpe比等权高37%。"

### 谈A股特殊性时

✅ 好的回答：
> "A股有几个关键不同点：(1) T+1交割限制了做空和日内套利，短期反转因子效果更强；(2) 涨跌停限制了信号传导速度，信号需要多日才能完全释放；(3) 散户占比高（历史上>80%），行为偏差更严重，短期反转、情绪类因子有更强的截面预测力；(4) 印花税（单边0.1%）显著提高了换手成本，高换手因子的净收益会被大幅侵蚀。"
